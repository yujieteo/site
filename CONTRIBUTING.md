# Contributing

1. Edit sources under `data/`, `scripts/`, `templates/`, `static/`, `schema/`, or `tests/`. Never hand-edit `site/`; it is regenerated by `scripts/build.py`.
2. Pick the matching playbook from [SKILLS.md](SKILLS.md); it lists the exact steps for each kind of change.
3. Before opening a pull request, run the commands in [README.md](README.md#build) and [README.md](README.md#test) and commit the resulting `site/` diff. CI fails when `site/` is stale.
4. Keep the diff scoped to the request, and never commit credentials, hostnames, or private paths.
