Subsets cut by scripts/fonts.sh with hb-subset (harfbuzz 13.2.1). Latin, Greek and typographic marks.
Fira Math and Serif Math keep the OpenType MATH table and add the operators, arrows, accents, letterlike
and double-struck capitals, and the bold and italic alphabets.
Default set-up: serif.otf plus serif-math.otf. Fira set-up: sans.otf plus math.otf. Source Serif 4 uses Serif Math.
Inter and OpenDyslexic use Fira Math.
BaskervilleF is a fork of Libre Baskerville. It is not Storm Baskerville or Fry's Baskerville.
GUST Font Licence (LPPL-based): it allows modification and redistribution. It asks that a modified font gets
a new name. The subset has a new internal family name ("Serif Math"), a new file name and a new CSS alias.
To use licensed fonts, replace serif.* and serif-math.* with the licensed files (same names, .otf or .ttf).
The CSS aliases are role-based, so nothing else changes. No commercial font is stored here.
