#What does Marklove do?

You write one Markdown file. Marklove makes slides, an article, a handout, a poster, an interactive web page, videos, narration and a podcast from that file. It works on iPhone, iPad and Mac.

#How do I start?

On the first launch, read the welcome pages, then select Open the Tour. The tour project shows each main feature. To see the welcome again, open Help.

#How do I export?

Select Export. The default is all outputs in one ZIP file. You can also select one format. Every export format is free.

#How do I add narration?

Write the spoken text in a ::: narration block. For the narrated video and the podcast, go to Settings › Narration and select Download the Voice one time (333 MB, use Wi-Fi). After that, narration works offline. To use a different voice, add voice: to the front matter, for example voice: bf_emma.

#What is Marklove Pro? Is it a subscription?

No. Marklove Pro is a one-time purchase of US$19.99. You pay once and keep it. One purchase unlocks Pro on iPhone, iPad and Mac with the same Apple Account. Pro adds unlimited projects, the custom accent colour and the optional Vim mode.

#How do I restore my purchase?

Open Settings in the app and select Restore Purchases. Use the same Apple Account that you bought with.

#How do I ask for a refund?

Apple handles refunds. Go to reportaproblem.apple.com.

#How do I back up a project?

In the project menu, select Save a ZIP Copy. The ZIP file has your Markdown file, your images and media, and the version history (.git). On a Mac, the Finder hides .git; press ⌘⇧. to show it. To bring a project back, select Import Markdown or ZIP.

#How do I use Find and the Sam commands?

Find uses the patterns of sam, the editor of Plan 9, by default. Settings › Find patterns selects Sam, Vim or plain text. Help › Sam Tutorial teaches the commands with live examples.

#Who made Marklove?

Marklove was made with help from Claude, an AI model by Anthropic. The app sends no data to AI services. Narration uses the Kokoro speech model on your device.

#Accessibility

Marklove works with VoiceOver, and reads equations in words. The editor has VoiceOver rotors for slides and sections. Dynamic Type, Bold Text, Increase Contrast, Reduce Motion, Smart Invert and dark mode are supported. Slides keep their fixed text size; the reading view follows Dynamic Type.
