A clear thought is usually pictured as one thing: a description with the fog
removed. Unambiguous. Confident. Simple. Unemotional. That picture is a useful
first approximation, and it is the one most advice about thinking assumes. It
also breaks as soon as you notice a sentence that is unambiguous and useless, or
a rough sketch that answers exactly the question you had.

The picture hides the question that decides the answer: clear *to do what?*

When I call a thought clear, I am grading a representation — a sentence, a
diagram, a model, a plan — by whether it serves the task it is being used for.
Drop the task and the word has no standard left to meet. A subway map is clear
for planning a route because it throws away distance and true geography. A
survey map is clear for measuring a plot because it keeps them. Neither map is
the clearer one; they are clear for different jobs.

Most disagreements about whether something is clear are really disagreements
about the job. Three jobs are common enough to name.

## Deciding

A representation used to choose is clear when it separates the actions you can
actually take and preserves the signal that would tell you the choice was wrong.
Detail is not the measure. A one-line rule of thumb can be clear for choosing if
it ranks your real options; a fifty-page report can be unclear if every option
reads the same.

The characteristic failure is a description that is easy to read and leaves the
options indistinguishable. Ease of reading is not nothing — it comes from
familiar words, short sentences, and a shape you have seen before — but none of
those are produced by fit to the decision. They are produced by fluency, and
fluency is a poor gauge of whether the description kept what your choice needs.

## Explaining

A representation used to explain is clear when a listener can rebuild cases you
did not cover. The test is not whether they can repeat the sentences back. Ask
them to answer a question you never answered. If they can, the description
carried the structure rather than the wording. If they can only echo you, they
learned a look.

## Discovering

A representation used to find something new is clear when it can be wrong. It
has to name what would count against it. A model that cannot be contradicted
cannot be corrected, however tidy it is.

This is the job where a fuzzy statement sometimes beats a sharp one. A question
posed too precisely can close off the case that did not fit, and the case that
did not fit is often the one worth finding. The discomfort of not knowing which
category a case belongs to is information when the available categories cut
across it: the unease is the boundary showing through. The honest move is to say
which distinction the categories lose — not to force the case into the nearest
bin.

Not all confusion is insight, though. "It's complicated" explains nothing;
neither does "emergence" or "a skill issue" when used as a label. If the cause is
unknown, say which piece is missing. If a mechanism is available, give it.

## The old picture, revised

"Seeing things as they are" is not wrong, it is underspecified. It survives as
informal shorthand for a common case: you want a description other people can
trust without knowing your private purpose. That is why "neutral" and "unbiased"
feel like synonyms for clear. For that job, stripping the teller's preferences
out is real work and the right work. For choosing under a deadline, or for
noticing what everyone else has smoothed over, that same stripping can remove
the very thing the job needed.

The precise version is narrower and more useful: clarity is a fit between a
representation and a stated job. The shorthand survives because the sharing job
is common. It should not be allowed to stand in for the rest.

## A label to stop using

When "you're not thinking clearly" arrives after someone disagrees, the
definition has been stretched to protect a conclusion. If clarity means
agreement with the speaker, the boundary is doing rhetorical work. The label can
still be fair — but only with the job named and the failure stated. "Your plan
does not distinguish two options you can't both take" is a claim that can be
checked. "You're confused" is not.

## One decision is not a rule

A blunt summary that settled one meeting shows that this decision needed few
distinctions. It is not evidence that bluntness is a rule. The temptation to
generalize from a single success is strongest exactly where the reasoning is
thinnest.

## What to do with this

When a question feels stuck, the work is often not more thinking but naming the
job. Write the answer to "what is this description for?" and check it with one
small test:

- For a decision: list the live options and one observation that would flip
  their order.
- For an explanation: ask someone to work a case you did not mention.
- For discovery: write the sentence that would be false if the idea were wrong.

This is worth trying because a description whose job was never named has no way
to fail, and so no way to be fixed. It is not a guarantee: some questions are
unresolved because the evidence is not in yet, and a clearer question does not
manufacture an answer.

Clarity is not a state to reach and keep. It is a relationship between a
description and a use, and the use can change. Ask what the thought is for, and
"is this clear?" becomes answerable — not everywhere, but exactly where you
need it.
