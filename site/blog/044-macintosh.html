Macintosh Setup

I do not use configuration files. Set up is meant to be maximally replicable in cases of destruction.

Checklist

  1. Visit brew.sh (or chocolatey for windows), set up dark mode, set up networking.
  2. brew install git
  3. brew install --cask visual-studio-code, alternatively visit [Visual Studio Code](https://code.visualstudio.com). Login to github. VScode all relevant extensions.
  4. brew install vim
  5. brew install anki
  6. make folders all on home directory, flat directory, git clone into it. git clone repo.
  7. brew install --cask firefox
  8. Set up the pipeline: C code to html to blog work flow. I use saait static page generator.
  9. Set up custom mail to web domain.
  10. brew install --casks mactex
