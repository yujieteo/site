7. SSH

Based on:

https://teoyujie.org/blog/051-ssh-guide.html

Create secure directory:

mkdir -p ~/.ssh
chmod 700 ~/.ssh

Check existing keys:

ls -al ~/.ssh

Generate Ed25519 key:

ssh-keygen -t ed25519 -C "YOUR_EMAIL"

Start agent:

eval "$(ssh-agent -s)"

Load key:

ssh-add ~/.ssh/id_ed25519

Permissions:

chmod 600 ~/.ssh/id_ed25519
chmod 644 ~/.ssh/id_ed25519.pub

Add public key to GitHub:

gh ssh-key add ~/.ssh/id_ed25519.pub \
    --title "MacBook"

Test:

ssh -T git@github.com

Clone over SSH:

git clone git@github.com:USER/REPO.git

Convert existing repository:

git remote set-url origin git@github.com:USER/REPO.git

Debug:

ssh-add -l
ssh -vT git@github.com

For a server:

cat ~/.ssh/id_ed25519.pub | \
ssh USER@SERVER \
'mkdir -p ~/.ssh &&
chmod 700 ~/.ssh &&
cat >> ~/.ssh/authorized_keys &&
chmod 600 ~/.ssh/authorized_keys'

Test:

ssh USER@SERVER

Optional ~/.ssh/config:

Host myserver
    HostName SERVER
    User USER
    IdentityFile ~/.ssh/id_ed25519
    IdentitiesOnly yes

Then:

ssh myserver

Never commit:

~/.ssh/id_ed25519

The public key may be copied freely:

~/.ssh/id_ed25519.pub

8. Secrets

Secrets remain ordinary text files.

They are protected by:

FileVault
Unix permissions
offline encrypted backup

Create:

mkdir -p ~/.secrets
chmod 700 ~/.secrets

Create separate domains:

touch ~/.secrets/ai.env
touch ~/.secrets/openclaw.env
touch ~/.secrets/discord.env
touch ~/.secrets/domain.env

Lock:

chmod 600 ~/.secrets/*.env

Example:

OPENAI_API_KEY='...'
ANTHROPIC_API_KEY='...'

Check:

ls -la ~/.secrets

Expected permissions:

drwx------ .secrets
-rw------- *.env

Do not globally export secrets from .zshrc.

Add this helper to .zshrc:

withsecrets() {
    secret_file="$HOME/.secrets/$1.env"
    shift

    if [ ! -f "$secret_file" ]; then
        echo "Missing $secret_file" >&2
        return 1
    fi

    (
        set -a
        . "$secret_file"
        set +a
        exec "$@"
    )
}

Use:

withsecrets ai python script.py

or:

withsecrets openclaw openclaw

Secrets exist only in the child process environment.

Never put secrets in:

Git
.zshrc
.gitconfig
mise.toml
shell history
.env committed to Git

Repositories may contain:

.env.example

Example:

OPENAI_API_KEY=
DISCORD_TOKEN=
DATABASE_URL=

Offline backup:

  1. Format a USB drive as encrypted APFS.
  2. Mount it.
  3. Copy:
rsync -a ~/.secrets/ /Volumes/SECRETS/secrets/

Verify:

diff -rq ~/.secrets /Volumes/SECRETS/secrets

Keep at least one encrypted copy physically separate from the Mac.

14. install.sh

#!/bin/sh

set -eu

mkdir -p "$HOME/.config"
mkdir -p "$HOME/.ssh"
mkdir -p "$HOME/.secrets"
mkdir -p "$HOME/Library/Application Support/Code/User"

chmod 700 "$HOME/.ssh"
chmod 700 "$HOME/.secrets"

ln -sf \
    "$HOME/src/configuration/.zshrc" \
    "$HOME/.zshrc"

ln -sf \
    "$HOME/src/configuration/.gitconfig" \
    "$HOME/.gitconfig"

ln -sf \
    "$HOME/src/configuration/.gitignore_global" \
    "$HOME/.gitignore_global"

rm -rf "$HOME/.config/nvim"

ln -s \
    "$HOME/src/configuration/config/nvim" \
    "$HOME/.config/nvim"

ln -sf \
    "$HOME/src/configuration/vscode/settings.json" \
    "$HOME/Library/Application Support/Code/User/settings.json"

ln -sf \
    "$HOME/src/configuration/ssh/config" \
    "$HOME/.ssh/config"

chmod 600 "$HOME/.ssh/config"

vim.opt.swapfile = false

vim.cmd.colorscheme("habamax")

local lazypath = vim.fn.stdpath("data") .. "/lazy/lazy.nvim"

if not vim.uv.fs_stat(lazypath) then
    vim.fn.system({
        "git",
        "clone",
        "--filter=blob:none",
        "https://github.com/folke/lazy.nvim.git",
        "--branch=stable",
        lazypath,
    })
end

vim.opt.rtp:prepend(lazypath)

require("lazy").setup({
    {
        "neovim/nvim-lspconfig",
        config = function()
            vim.lsp.enable({
                "pyright",
                "texlab",
            })
        end,
    },

    {
        "mfussenegger/nvim-lint",
        config = function()
            local lint = require("lint")

            lint.linters_by_ft = {
                python = { "ruff" },
                tex = { "chktex" },
            }

            vim.api.nvim_create_autocmd({
                "BufEnter",
                "BufWritePost",
                "InsertLeave",
            }, {
                callback = function()
                    lint.try_lint()
                end,
            })
        end,
    },
})

vim.diagnostic.config({
    virtual_text = true,
    signs = true,
    underline = true,
    update_in_insert = false,
    severity_sort = true,
})

vim.keymap.set("n", "gd", vim.lsp.buf.definition)
vim.keymap.set("n", "gr", vim.lsp.buf.references)
vim.keymap.set("n", "K", vim.lsp.buf.hover)
vim.keymap.set("n", "<leader>rn", vim.lsp.buf.rename)
vim.keymap.set("n", "<leader>ca", vim.lsp.buf.code_action)
vim.keymap.set("n", "<leader>d", vim.diagnostic.open_float)
