Spec R[x] as C modulo conjugation

It is a good idea that for any field k, the closed points of the affine line over k in dimension n is in bijection with the Galois orbits of the algebraic closure of k. Example, real valued polynomials have pairs of conjugate roots or purely real roots subsumed as one root. So Spec R[x] is Spec C modulo conjugation.
