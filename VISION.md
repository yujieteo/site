# Vision

This site exists so that Yu Jie Teo can publish posts with interactions.
It serves readers of those posts.
It owns one thing: the posts.

## Posts

- A post is as good as already-clean.goodfire.com.
- A reader can move things in a post. A figure is not a still picture.
- Every figure has a caption and alt text.
- Every post has a text version in Markdown.
- Every post has a download limit. The build fails over it.

## Design

- The look is the look of emilkowal.ski. It is light only.
- Motion is short. A reader can pause it.
- Reduced motion is respected.

## Code

- The code is TypeScript. Bun builds it.
- The site has no framework and no database.
- Evals prove the site. There are no native tests.
- The gate runs before every deploy.

## Scope

- The site is not a store of apps.
- The site has no privacy pages and no support pages.
- A post can have its full tool at `/play/`. The tool runs in the browser. Its post links it only in the data section at the end.
- A tool that needs a server stays in its repository. The post links the repository.
- The site has no log, no feed and no comments.
- The site has no old posts. All of them were removed.

## Life

- EXPIRY holds a date three months out.
- When it passes, rethink the playbook or rebuild the site.
- The blueprint changes first. Then the site is rebuilt from it.

## Judging a change

A change aligns when it helps a reader read or move a post.
A change should be resisted when it adds a page that is not a post.
