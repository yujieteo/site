This is my typical weekday schedule as of September 2026. Times use the
24-hour clock.

The day has a simple shape. The work day holds four 90-minute blocks, with a
break or lunch between each pair. A shutdown ritual closes the work day. The
evening holds a swim and yoga.

## Morning

| Time | Activity |
| --- | --- |
| 05:45 | Wake up |
| 06:20 | Shower |
| 06:30 | Breakfast |
| 07:00 | Commute to work, arrival |
| 08:00 | Walk, start work |

## Work day

| Time | Activity |
| --- | --- |
| 08:00 – 09:30 | Block 1 |
| 09:30 – 10:00 | Break |
| 10:00 – 11:30 | Block 2 |
| 11:30 – 13:00 | Lunch and walk |
| 13:00 – 14:30 | Block 3 |
| 14:30 – 15:00 | Break |
| 15:00 – 16:30 | Block 4 |
| 16:30 – 17:30 | Shutdown ritual |

## Evening

| Time | Activity |
| --- | --- |
| 17:30 – 18:00 | Bus ride home |
| 18:00 – 18:30 | Prep for swim |
| 18:30 – 19:30 | Swim |
| 19:30 – 20:00 | Dinner |
| 20:00 – 21:00 | Yoga |
| 21:00 – 22:30 | Rest |
