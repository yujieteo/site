The feeling to expect is irritation, or a fear of being slow, as each line needs a relation from three lines back. That is how these computations go for everyone. Take them at walking pace. If you want to see why quadratic forms and K-theory belong to one object, this is where the two meet. Play with the relations for fun. Getting to the last page is secondary.

## The story

Milnor K-theory of a field F records symbols. The Grothendieck–Witt ring GW(F) records quadratic forms. Milnor's maps link the two only after passing to quotients. People wanted a single graded ring that sees both before any quotient is taken. Morel's answer is to keep Milnor's generators [a] and add one new generator η in degree −1. The rule [ab] = [a] + [b] is bent by an η term, and one more relation, the Witt relation, is imposed. Then the element ⟨a⟩ = 1 + [a]η behaves like the one-dimensional form aX². Degree 0 of the new ring is GW(F), every negative degree is the Witt ring W(F), and killing η gives Milnor K-theory back.

## Main definitions

**Milnor–Witt K-theory.** K<sup>MW</sup><sub>∗</sub>(F) is the free associative ring on [a] for a ∈ F<sup>×</sup> (degree 1) and η (degree −1), modulo four relations. It is ℤ-graded.
- Twisted logarithm and Steinberg: [ab] = [a] + [b] + [a][b]η, and [a][b] = 0 when a + b = 1.
- Commutativity and Witt: η[a] = [a]η, and (2 + [−1]η)η = 0.

**The elements ⟨a⟩, h, ε.** Set ⟨a⟩ = 1 + [a]η, h = 1 + ⟨−1⟩ and ε = −⟨−1⟩, all in degree 0. Here ⟨a⟩ stands for the form aX² and h for the hyperbolic plane. The Witt relation is the same as hη = 0, and also the same as εη = η.

**Grothendieck–Witt and Witt rings.** GW(F) is generated by classes ⟨a⟩ subject to ⟨ab²⟩ = ⟨a⟩, ⟨a⟩ + ⟨−a⟩ = ⟨1⟩ + ⟨−1⟩ and ⟨a⟩ + ⟨b⟩ = ⟨a + b⟩ + ⟨(a + b)ab⟩ for a + b ≠ 0. The Witt ring is W(F) = GW(F)/(h).

**The ring J<sup>∗</sup>(F).** Let I(F) be the ideal of even-dimensional forms in W(F). Define J<sup>n</sup>(F) as the pullback of I<sup>n</sup>(F) and K<sup>M</sup><sub>n</sub>(F) over I<sup>n</sup>(F)/I<sup>n+1</sup>(F), using Milnor's map from symbols to Pfister forms.
- For n &lt; 0, read I<sup>n</sup>(F) as W(F), so J<sup>n</sup>(F) = W(F).
- For n = 0, J<sup>0</sup>(F) ≅ GW(F).

## Main results

**Proposition (η = 0 gives Milnor; Proposition 1).** For any field F, K<sup>MW</sup><sub>∗</sub>(F)/(η) ≅ K<sup>M</sup><sub>∗</sub>(F).

**Lemma (basic identities; Lemmas 2 and 3).** For all a, b ∈ F<sup>×</sup>: ⟨ab⟩ = ⟨a⟩⟨b⟩, ⟨a²⟩ = 1, ⟨a⟩ + ⟨−a⟩ = h, [a][−a] = 0, and [a][b] = ε[b][a]. The last identity is the ε-graded commutativity that replaces the sign rule of Milnor K-theory.
- Step 1: multiply the twisted logarithm relation by η to get multiplicativity of ⟨ ⟩.
- Step 2: write −a = (1 − a)/(1 − 1/a) and use the Steinberg relation.

**Proposition (non-positive degrees; Proposition 5).** The assignment ⟨a⟩ ↦ ⟨a⟩ gives isomorphisms GW(F) ≅ K<sup>MW</sup><sub>0</sub>(F) and W(F) ≅ K<sup>MW</sup><sub>n</sub>(F) for every n &lt; 0. Multiplication by η from degree 0 to degree −1 matches the quotient GW(F) → W(F).
- Step 1: the lemma shows the relations of GW(F) hold in degree 0, so the maps are well defined and surjective.
- Step 2: the map K<sup>MW</sup><sub>∗</sub>(F) → J<sup>∗</sup>(F) gives an inverse on these degrees.

**Theorem (Theorem 6).** The canonical map K<sup>MW</sup><sub>∗</sub>(F) → J<sup>∗</sup>(F) is an isomorphism of graded rings. The notes state this and leave the proof blank, with a pointer to a reference.

## Note, then ignore

- No characteristic hypothesis is stated. The notes say "any field", while the presentation of GW(F) by diagonal forms is usually used away from characteristic 2. I could not check from the notes how characteristic 2 is handled. Safe to skip on a first reading.
- Missing citations. The reference marks print as "[?]" in the file, including the source for Theorem 6. The intended source is Morel's work. Safe to skip.
- Order of factors. The ring is not commutative, so [a][b]η and η[a][b] need the commutativity relation to compare. Degree 0 turns out to be central. Safe to skip.
- Milnor's conjecture. A footnote recalls that I<sup>n</sup>/I<sup>n+1</sup> is K<sup>M</sup><sub>n</sub>(F)/2. The notes do not use it here. Safe to skip.
- Overloaded symbols. The letters η and [a] are reused for elements of J<sup>∗</sup>(F). This is done so the comparison map is easy to state. Safe to skip.
